‏Sound Tuner הוא אקולייזר, מפצל תדרים (crossover) וכלי כוונון רמקולים ברמת המערכת
לשולחנות עבודה בלינוקס שרצים על PipeWire. הוא מוסיף פלט וירטואלי, **Sound Tuner**,
לפני כל התקן שמע, מהרמקולים המובנים של לפטופ ועד זוג סטריאו
עם סאב־וופר או מערכת 7.1 מלאה, וכל האפליקציות מתנגנות דרכו.

## תכונות

- **אקולייזר שאפשר לצייר:** מעבירים את העכבר לאורך הגרף בכל כיוון כדי לצייר
  את העקומה, או גוררים נקודות בודדות. העקומה עוברת דרך הנקודות שלכם
  (האפליקציה מחשבת בשבילכם את ההגבר של המסננים), ואפשר לגלול כדי להרחיב
  או לצמצם רצועה, או להקליד ערכים מדויקים של תדר, הגבר ורוחב.
  **ספקטרום חי** של מה שמתנגן מצויר מאחורי העקומה.
- **ניתוב ומפצלי תדרים לכל ערוץ, בכל תצורה** (2.0, 2.1, 4.0, 5.1,
  7.1, …). לכל ערוץ רמקול מגדירים:
  - את המקור: אותו ערוץ, שמאל, ימין, מונו, כל הערוצים (לסאב־וופר) או כבוי
  - מסנני מעביר גבוהים ומעביר נמוכים (Linkwitz-Riley, ‏24 dB/אוקטבה)
  - רמה, השהיה (ליישור זמנים) וקוטביות
- **תצורות ערוצים בלחיצה אחת:** חיתוך נמוכים לרמקולים קטנים, פיצול בס בשמאל /
  טרבל בימין ללפטופים, סטריאו לכל הרמקולים, וניהול בס ב־80 Hz
  למערכות עם סאב־וופר.
- **עוצמה:** עד ‎+20 dB הגברה לתוך מגביל עם מבט קדימה (ZaMaximX2),
  ועוד **אוברדרייב** אופציונלי למקרים שרוצים יותר חזק ממה שצליל נקי מאפשר,
  ומתג שמאפשר למחוון העוצמה של GNOME לעבור את 100%.
- **‏3D:** רוחב סטריאו בתוספת ביטול הצלבה (crosstalk) בסגנון
  Ambiophonics/RACE, שפורש את הצליל רחב יותר מרמקולים צמודים
  כמו אלה של לפטופ.
- **ערכות מוגדרות:** רשימה בראש החלון. לוחצים על ערכה כדי לטעון אותה, או שומרים את
  הצליל הנוכחי כערכה חדשה. השינויים נשמרים בערכה הפעילה תוך כדי עבודה.

## איך זה בהשוואה ל־Easy Effects, ‏JamesDSP ודומיהם

- **ממשק מודרני ופשוט:** מסך אחד נקי. מציירים את עקומת האקולייזר, מגדירים עוצמה
  ו־3D ובוחרים ערכה, בלי לחפור בלוחות של תוספים. הוא גם
  מותאם לנייד, ומסתגל מטלפונים ועד מסכי מחשב רחבים.
- **שום דבר לא צריך להמשיך לרוץ:** העיבוד מתבצע בתוך PipeWire עצמו. סוגרים
  את האפליקציה והצליל נשאר מכוונן מרגע הכניסה למערכת.
- **רב־ערוצי אמיתי:** ‏5.1 נשאר 5.1, עם מפצלי תדרים, השהיות
  וניהול בס לכל ערוץ.
- **בלי ניתוקים:** השינויים מוחלים על המסנן הפועל בזמן אמת.
- **זעיר:** קובץ Python אחד וקובץ תצורה קריא אחד של PipeWire.
- **קשה לגרום לקטיעה:** השרשרת תמיד מסתיימת במגביל עם מבט קדימה. פרטים בהמשך.

### למה אפליקציות אקולייזר אחרות יכולות להישמע מעוותות

אקולייזר והגברת בס יכולים לדחוף את האות מעבר ל־0 dBFS, המקסימום ששבב השמע
יכול לנגן, והוא נקטע אלא אם מגביל תופס אותו. ‏Sound Tuner תמיד מסתיים
במגביל עם מבט קדימה שמכוון מתחת ל־0 dBFS, כך שהגברות נשמעות חזקות יותר במקום
לפצפץ. (אוברדרייב עוקף את זה בכוונה.) בנוסף, העיבוד מתבצע
בתוך PipeWire עצמו ולא בתהליך נפרד של אפליקציה, כך שיש תוכנה אחת
פחות שצריכה לעמוד בקצב בזמן אמת.

## התקנה

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

הסקריפט מתקין את כל התלויות החסרות בעזרת מנהל החבילות שלכם (dnf,
apt או pacman). הוא מציג את הפקודה המדויקת ושואל לפני שימוש ב־`sudo`. לאחר מכן
הוא מתקין את האפליקציה למשתמש שלכם בלבד.

פותחים את **Sound Tuner**, בוחרים את התקן הפלט ולוחצים על **טעינה** בפס
ההודעה. השמע מופעל מחדש פעם אחת כדי לטעון את המסנן.

| אפשרות | מה היא עושה |
|---|---|
| `--yes` | מתקינה תלויות בלי לשאול |
| `--no-deps` | מדלגת על תלויות ומתקינה את האפליקציה בלבד |
| `--dry-run` | מציגה מה יותקן בלי לשנות דבר |
| `--uninstall` | מסירה את האפליקציה ואת מסנן PipeWire (הערכות שלכם נשמרות) |

### תלויות

מותקנות בשבילכם על ידי `install.sh`:

- כלי PipeWire: ‏`pw-cli`, ‏`pw-dump`, ‏`pw-record` ו־`pactl`
- ‏Python 3 עם GTK 4 ו־libadwaita 1.5+
- המגביל ZaMaximX2 מתוך [zam-plugins](https://github.com/zamaudio/zam-plugins)
- תמיכת LV2 של PipeWire עבור filter-chain

צריך שולחן עבודה שכבר רץ על PipeWire עם WirePlumber, שזו
ברירת המחדל בגרסאות הנוכחיות של Fedora, ‏Ubuntu, ‏Debian ו־Arch. שמות החבילות של Fedora
נבדקו; בהפצות אחרות, אם שם של חבילה השתנה, הסקריפט יגיד לכם
מה חסר כדי שתוכלו להתקין אותו בעצמכם.

## איך זה עובד

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

מבנה הגרף תלוי רק בערוצים של ההתקן. כל השאר
הוא פרמטר, וכיבוי תכונה מעביר אותה לערך ניטרלי, כמו
0 dB או מסנן שהוזז אל מחוץ לטווח השמיעה.

אפקט ה־3D הוא RACE שנפרש לשני איברים:
`out = own − g·D(other) + g²·D₂(own)`, מוגבל לתחום 250 Hz–5 kHz. גרפי המסננים של PipeWire
לא יכולים להכיל לולאות משוב, ולכן הוא לא רקורסיבי לגמרי.

הספקטרום נקרא בעזרת `pw-record` מההתקן שאתם מכווננים, ורק
כשהחלון פתוח.

## טיפים

- **לפטופים:** החילו את התצורה *רמקולים קטנים* (חיתוך נמוכים ב־120 Hz) והוסיפו
  ‏6–10 dB הגברה. זה בערך מה ששיפורי Windows כמו Dolby עושים
  ברוב הלפטופים.
- **סאב־וופר:** החילו את *ניהול בס (80 Hz)*, ואז כווננו את
  הרמה וההשהיה של הסאב־וופר עד שהבס נשמע אחיד במקום הישיבה שלכם.
- **‏3D:** שבו במרכז, הגדירו את עוצמת ה־3D לכ־70%, ואז הזיזו את השהיית ה־3D עד
  שהצליל מתפרש רחב יותר מהרמקולים.
- **אוברדרייב** שולח לרמקולים שמע קטוע. השתמשו בו במשורה עם
  רמקולים קטנים.
