Sound Tuner — общесистемный эквалайзер, кроссовер и настройщик динамиков для
Linux-десктопов на PipeWire. Он добавляет виртуальный выход **Sound Tuner**
перед любым звуковым устройством — от встроенных динамиков ноутбука до
стереопары с сабвуфером или полноценной системы 7.1, — и все приложения
играют через него.

## Возможности

- **Эквалайзер, который можно рисовать:** проведите по графику в любую
  сторону, чтобы нарисовать кривую, или перетаскивайте отдельные точки. Кривая
  проходит через ваши точки (усиление фильтров приложение рассчитает само),
  а прокруткой можно сделать полосу шире или уже либо ввести точные значения
  частоты, усиления и ширины. За кривой отображается **живой спектр** того,
  что сейчас играет.
- **Маршрутизация и кроссоверы для каждого канала при любой раскладке** (2.0,
  2.1, 4.0, 5.1, 7.1, …). Для каждого канала динамика задаются:
  - источник: тот же канал, левый, правый, моно, все каналы (для сабвуфера) или выкл.
  - кроссоверные фильтры ВЧ и НЧ (Linkwitz-Riley, 24 dB/oct)
  - уровень, задержка (для выравнивания по времени) и полярность
- **Схемы каналов в один клик:** срез низов для маленьких динамиков,
  разделение «левый — басы, правый — высокие» для ноутбуков, стерео на все
  динамики и управление басами на 80 Hz для систем с сабвуфером.
- **Громкость:** до +20 dB подъёма с лимитером с упреждением (ZaMaximX2),
  а также необязательный **овердрайв** — для случаев, когда нужно громче, чем
  позволяет чистый звук, — и переключатель, позволяющий ползунку громкости
  GNOME заходить за 100%.
- **3D:** ширина стерео плюс подавление перекрёстных помех в духе
  Ambiophonics/RACE, которое раскрывает звук шире, чем позволяют близко
  стоящие динамики, например в ноутбуке.
- **Пресеты:** список вверху окна. Щёлкните по пресету, чтобы загрузить его,
  или сохраните текущий звук как новый. Изменения сохраняются в активный пресет
  по ходу дела.

## Чем он отличается от Easy Effects, JamesDSP и т. п.

- **Современный и простой интерфейс:** один аккуратный экран. Рисуете кривую
  эквалайзера, настраиваете громкость и 3D, выбираете пресет — и никаких
  раскопок в панелях плагинов. Он ещё и дружит с мобильными устройствами:
  подстраивается и под телефоны, и под широкие мониторы.
- **Ничего не нужно держать запущенным:** обработка идёт внутри самого
  PipeWire. Закройте приложение — звук останется настроенным с момента входа
  в систему.
- **Настоящая многоканальность:** 5.1 остаётся 5.1, с кроссоверами,
  задержками и управлением басами для каждого канала.
- **Никаких пропаданий звука:** изменения применяются к работающему фильтру
  на лету.
- **Крошечный:** один файл на Python и один читаемый конфиг PipeWire.
- **Клиппинг почти невозможен:** цепочка всегда заканчивается лимитером
  с упреждением. Подробнее ниже.

### Почему другие эквалайзеры могут звучать с искажениями

Эквалайзер и подъём басов могут вывести сигнал за 0 dBFS — максимум, который
способен воспроизвести звуковой чип, — и тогда происходит клиппинг, если его
не перехватит лимитер. Sound Tuner всегда заканчивает цепочку лимитером
с упреждением, выставленным ниже 0 dBFS, поэтому подъём делает звук громче,
а не хрипящим. (Овердрайв намеренно обходит это ограничение.) К тому же
обработка идёт внутри самого PipeWire, а не в отдельном процессе приложения,
так что на одну программу, которая должна успевать в реальном времени,
меньше.

## Установка

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

Скрипт устанавливает недостающие зависимости через ваш пакетный менеджер (dnf,
apt или pacman). Он показывает точную команду и спрашивает разрешения, прежде
чем использовать `sudo`. Затем он устанавливает приложение только для вашего
пользователя.

Откройте **Sound Tuner**, выберите устройство вывода и нажмите **Загрузить**
на баннере. Звук один раз перезапустится, чтобы загрузить фильтр.

| Параметр | Что делает |
|---|---|
| `--yes` | устанавливает зависимости без вопросов |
| `--no-deps` | пропускает зависимости, устанавливает только приложение |
| `--dry-run` | показывает, что было бы установлено, ничего не меняя |
| `--uninstall` | удаляет приложение и фильтр PipeWire (пресеты сохраняются) |

### Зависимости

Устанавливаются за вас скриптом `install.sh`:

- Инструменты PipeWire: `pw-cli`, `pw-dump`, `pw-record` и `pactl`
- Python 3 с GTK 4 и libadwaita 1.5+
- Лимитер ZaMaximX2 из [zam-plugins](https://github.com/zamaudio/zam-plugins)
- Поддержка LV2 в PipeWire для filter-chain

Нужен десктоп, на котором уже работает PipeWire с WirePlumber, — это вариант
по умолчанию в актуальных Fedora, Ubuntu, Debian и Arch. Названия пакетов
проверены на Fedora; если в другом дистрибутиве название пакета изменилось,
скрипт сообщит, чего не хватает, чтобы вы могли установить это сами.

## Как это работает

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

Структура графа зависит только от каналов устройства. Всё остальное — это
параметры, а выключение функции просто выставляет нейтральное значение,
например 0 dB или фильтр, сдвинутый за пределы слышимого диапазона.

Эффект 3D — это RACE, развёрнутый до двух членов:
`out = own − g·D(other) + g²·D₂(own)`, с ограничением полосы 250 Hz–5 kHz.
Графы фильтров PipeWire не могут содержать петель обратной связи, поэтому
он не полностью рекурсивный.

Спектр снимается через `pw-record` с настраиваемого устройства и только пока
открыто окно.

## Советы

- **Ноутбуки:** примените схему *Маленькие динамики* (срез ниже 120 Hz)
  и добавьте 6–10 dB подъёма. Примерно это и делают улучшения звука в Windows
  вроде Dolby на большинстве ноутбуков.
- **Сабвуфер:** примените *Управление басами (80 Hz)*, затем подстройте
  уровень и задержку сабвуфера, пока бас не зазвучит ровно на вашем месте.
- **3D:** сядьте по центру, выставьте силу 3D примерно на 70%, затем меняйте
  задержку 3D, пока звук не раскроется шире динамиков.
- **Овердрайв** подаёт на динамики звук с клиппингом. Используйте его
  осторожно на маленьких динамиках.
