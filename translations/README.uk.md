Sound Tuner — загальносистемний еквалайзер, кросовер і налаштовувач динаміків
для Linux-десктопів на PipeWire. Він додає віртуальний вихід **Sound Tuner**
перед будь-яким звуковим пристроєм — від вбудованих динаміків ноутбука до
стереопари із сабвуфером чи повноцінної системи 7.1, — і всі застосунки
грають через нього.

## Можливості

- **Еквалайзер, який можна малювати:** проведіть по графіку в будь-який бік,
  щоб намалювати криву, або перетягуйте окремі точки. Крива проходить через
  ваші точки (підсилення фільтрів застосунок розрахує сам), а прокручуванням
  можна зробити смугу ширшою чи вужчою або ввести точні значення частоти,
  підсилення та ширини. За кривою відображається **живий спектр** того, що
  зараз грає.
- **Маршрутизація та кросовери для кожного каналу за будь-якої розкладки**
  (2.0, 2.1, 4.0, 5.1, 7.1, …). Для кожного каналу динаміка задаються:
  - джерело: той самий канал, лівий, правий, моно, усі канали (для сабвуфера) або вимк.
  - кросоверні фільтри ВЧ і НЧ (Linkwitz-Riley, 24 dB/oct)
  - рівень, затримка (для вирівнювання в часі) та полярність
- **Схеми каналів в один клік:** зріз низів для малих динаміків, розподіл
  «лівий — баси, правий — високі» для ноутбуків, стерео на всі динаміки та
  керування басами на 80 Hz для систем із сабвуфером.
- **Гучність:** до +20 dB підйому з лімітером із випередженням (ZaMaximX2),
  а також необов’язковий **овердрайв** — коли хочеться гучніше, ніж дозволяє
  чистий звук, — і перемикач, що дає повзунку гучності GNOME виходити за 100%.
- **3D:** ширина стерео плюс придушення перехресних завад у дусі
  Ambiophonics/RACE, яке розкриває звук ширше, ніж дозволяють близько
  розташовані динаміки, як-от у ноутбуці.
- **Пресети:** список угорі вікна. Клацніть пресет, щоб завантажити його, або
  збережіть поточний звук як новий. Зміни зберігаються в активний пресет
  у процесі роботи.

## Чим він відрізняється від Easy Effects, JamesDSP тощо

- **Сучасний і простий інтерфейс:** один охайний екран. Малюєте криву
  еквалайзера, налаштовуєте гучність і 3D, обираєте пресет — і жодного
  копирсання в панелях плагінів. Він ще й дружній до мобільних: підлаштовується
  і під телефони, і під широкі монітори.
- **Нічого не треба тримати запущеним:** обробка відбувається всередині
  самого PipeWire. Закрийте застосунок — звук лишиться налаштованим від
  моменту входу в систему.
- **Справжня багатоканальність:** 5.1 лишається 5.1, із кросоверами,
  затримками та керуванням басами для кожного каналу.
- **Жодних пропадань звуку:** зміни застосовуються до запущеного фільтра на
  льоту.
- **Крихітний:** один файл на Python і один зрозумілий конфіг PipeWire.
- **Кліпінг майже неможливий:** ланцюжок завжди закінчується лімітером
  із випередженням. Докладніше нижче.

### Чому інші еквалайзери можуть звучати зі спотвореннями

Еквалайзер і підйом басів можуть вивести сигнал за 0 dBFS — максимум, який
здатен відтворити звуковий чип, — і тоді виникає кліпінг, якщо його не
перехопить лімітер. Sound Tuner завжди закінчує ланцюжок лімітером
із випередженням, налаштованим нижче 0 dBFS, тож підйом робить звук гучнішим,
а не хриплим. (Овердрайв навмисно обходить це обмеження.) До того ж обробка
відбувається всередині самого PipeWire, а не в окремому процесі застосунку,
тож на одну програму, яка мусить устигати в реальному часі, менше.

## Встановлення

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

Скрипт встановлює відсутні залежності через ваш пакетний менеджер (dnf, apt
або pacman). Він показує точну команду й питає дозволу, перш ніж використати
`sudo`. Потім він встановлює застосунок лише для вашого користувача.

Відкрийте **Sound Tuner**, оберіть пристрій виводу й натисніть **Завантажити**
на банері. Звук один раз перезапуститься, щоб завантажити фільтр.

| Параметр | Що робить |
|---|---|
| `--yes` | встановлює залежності без запитань |
| `--no-deps` | пропускає залежності, встановлює лише застосунок |
| `--dry-run` | показує, що було б встановлено, нічого не змінюючи |
| `--uninstall` | видаляє застосунок і фільтр PipeWire (пресети зберігаються) |

### Залежності

Встановлюються за вас скриптом `install.sh`:

- Інструменти PipeWire: `pw-cli`, `pw-dump`, `pw-record` і `pactl`
- Python 3 з GTK 4 і libadwaita 1.5+
- Лімітер ZaMaximX2 із [zam-plugins](https://github.com/zamaudio/zam-plugins)
- Підтримка LV2 у PipeWire для filter-chain

Потрібен десктоп, на якому вже працює PipeWire із WirePlumber, — це типовий
варіант в актуальних Fedora, Ubuntu, Debian і Arch. Назви пакетів перевірено
на Fedora; якщо в іншому дистрибутиві назва пакета змінилася, скрипт підкаже,
чого бракує, щоб ви могли встановити це самі.

## Як це працює

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

Структура графа залежить лише від каналів пристрою. Усе інше — це параметри,
а вимкнення функції просто виставляє нейтральне значення, наприклад 0 dB або
фільтр, зсунутий за межі чутного діапазону.

Ефект 3D — це RACE, розгорнутий до двох членів:
`out = own − g·D(other) + g²·D₂(own)`, з обмеженням смуги 250 Hz–5 kHz.
Графи фільтрів PipeWire не можуть містити петель зворотного зв’язку, тому
він не повністю рекурсивний.

Спектр знімається через `pw-record` із пристрою, який ви налаштовуєте, і лише
поки відкрите вікно.

## Поради

- **Ноутбуки:** застосуйте схему *Малі динаміки* (зріз нижче 120 Hz) і додайте
  6–10 dB підйому. Приблизно це й роблять покращення звуку у Windows на кшталт
  Dolby на більшості ноутбуків.
- **Сабвуфер:** застосуйте *Керування басами (80 Hz)*, потім підлаштуйте
  рівень і затримку сабвуфера, доки бас не звучатиме рівно на вашому місці.
- **3D:** сядьте по центру, виставте силу 3D приблизно на 70%, потім змінюйте
  затримку 3D, доки звук не розкриється ширше за динаміки.
- **Овердрайв** подає на динаміки звук із кліпінгом. Використовуйте його
  обережно на малих динаміках.
