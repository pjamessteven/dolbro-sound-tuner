Το Sound Tuner είναι ένας ισοσταθμιστής, crossover και ρυθμιστής ηχείων για
όλο το σύστημα, για επιτραπέζια περιβάλλοντα Linux που τρέχουν PipeWire.
Προσθέτει μια εικονική έξοδο, το **Sound Tuner**, μπροστά από οποιαδήποτε
συσκευή ήχου, από τα ενσωματωμένα ηχεία ενός laptop μέχρι ένα στερεοφωνικό
ζευγάρι με subwoofer ή ένα πλήρες σύστημα 7.1, και όλες οι εφαρμογές παίζουν
μέσα από αυτήν.

## Δυνατότητες

- **Ένας ισοσταθμιστής που τον ζωγραφίζετε:** σύρετε πάνω στο γράφημα προς
  οποιαδήποτε κατεύθυνση για να σχεδιάσετε την καμπύλη ή μετακινήστε μεμονωμένα
  σημεία. Η καμπύλη περνά από τα σημεία σας (η εφαρμογή υπολογίζει μόνη της
  την απολαβή των φίλτρων) και μπορείτε να κάνετε κύλιση για να φαρδύνετε ή
  να στενέψετε μια ζώνη ή να πληκτρολογήσετε ακριβείς τιμές συχνότητας,
  απολαβής και εύρους. Πίσω από την καμπύλη σχεδιάζεται ένα **ζωντανό φάσμα**
  αυτού που παίζει.
- **Δρομολόγηση και crossover ανά κανάλι για κάθε διάταξη** (2.0, 2.1, 4.0,
  5.1, 7.1, …). Για κάθε κανάλι ηχείου ορίζετε:
  - την πηγή: ίδιο κανάλι, αριστερό, δεξί, μονοφωνικό, όλα τα κανάλια (για subwoofer) ή ανενεργό
  - υψιπερατά και χαμηλοπερατά φίλτρα crossover (Linkwitz-Riley, 24 dB/oct)
  - στάθμη, καθυστέρηση (για χρονική ευθυγράμμιση) και πολικότητα
- **Διατάξεις καναλιών με ένα κλικ:** αποκοπή χαμηλών για μικρά ηχεία,
  διαχωρισμός αριστερό μπάσα / δεξί πρίμα για laptop, στερεοφωνικό σε όλα τα
  ηχεία και διαχείριση μπάσων στα 80 Hz για συστήματα με subwoofer.
- **Ακουστότητα:** έως +20 dB ενίσχυσης προς έναν περιοριστή πρόβλεψης
  (ZaMaximX2), συν προαιρετικό **overdrive** για όταν τον θέλετε πιο δυνατά
  απ’ όσο επιτρέπει ο καθαρός ήχος, και ένας διακόπτης που αφήνει το ρυθμιστικό
  έντασης του GNOME να ξεπεράσει το 100%.
- **3D:** στερεοφωνικό εύρος συν ακύρωση διαφωνίας (crosstalk) στο ύφος του
  Ambiophonics/RACE, που απλώνει τον ήχο πιο πλατιά απ’ ό,τι επιτρέπουν
  ηχεία τοποθετημένα κοντά μεταξύ τους, όπως αυτά ενός laptop.
- **Προρρυθμίσεις:** μια λίστα στο πάνω μέρος του παραθύρου. Κάντε κλικ σε
  μία για να τη φορτώσετε ή αποθηκεύστε τον τρέχοντα ήχο ως νέα. Οι αλλαγές
  αποθηκεύονται στην ενεργή προρρύθμιση καθώς προχωράτε.

## Σύγκριση με Easy Effects, JamesDSP κ.λπ.

- **Σύγχρονη, εύκολη διεπαφή:** μία καθαρή οθόνη. Σχεδιάστε την καμπύλη του
  ισοσταθμιστή, ρυθμίστε ακουστότητα και 3D και διαλέξτε προρρύθμιση, χωρίς
  να ψάχνετε σε πλαίσια πρόσθετων. Είναι φιλική και σε κινητά, προσαρμόζεται
  από τηλέφωνα μέχρι φαρδιές οθόνες υπολογιστή.
- **Τίποτα δεν χρειάζεται να μένει ανοιχτό:** η επεξεργασία γίνεται μέσα
  στο ίδιο το PipeWire. Κλείστε την εφαρμογή και ο ήχος σας μένει ρυθμισμένος
  από τη σύνδεση και μετά.
- **Πραγματικά πολυκαναλικό:** το 5.1 μένει 5.1, με crossover, καθυστερήσεις
  και διαχείριση μπάσων ανά κανάλι.
- **Χωρίς διακοπές ήχου:** οι αλλαγές εφαρμόζονται ζωντανά στο φίλτρο που
  τρέχει.
- **Μικροσκοπικό:** ένα αρχείο Python και ένα ευανάγνωστο αρχείο ρυθμίσεων
  PipeWire.
- **Δύσκολα ψαλιδίζει:** η αλυσίδα καταλήγει πάντα σε περιοριστή πρόβλεψης.
  Δείτε παρακάτω.

### Γιατί άλλες εφαρμογές ισοστάθμισης μπορεί να ακούγονται παραμορφωμένες

Ο ισοσταθμιστής και η ενίσχυση των μπάσων μπορούν να σπρώξουν το σήμα πέρα
από τα 0 dBFS, το μέγιστο που μπορεί να παίξει το τσιπ ήχου, και τότε
ψαλιδίζει, εκτός αν το πιάσει ένας περιοριστής. Το Sound Tuner τελειώνει
πάντα με έναν περιοριστή πρόβλεψης ρυθμισμένο κάτω από τα 0 dBFS, οπότε οι
ενισχύσεις ακούγονται πιο δυνατά αντί να τρίζουν. (Το overdrive το παρακάμπτει
σκόπιμα.) Επίσης, η επεξεργασία του γίνεται μέσα στο ίδιο το PipeWire και όχι
σε ξεχωριστή διεργασία εφαρμογής, άρα υπάρχει ένα πρόγραμμα λιγότερο που
πρέπει να προλαβαίνει σε πραγματικό χρόνο.

## Εγκατάσταση

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

Το σενάριο εγκαθιστά όσες εξαρτήσεις λείπουν με τον διαχειριστή πακέτων σας
(dnf, apt ή pacman). Δείχνει την ακριβή εντολή και ρωτά πριν χρησιμοποιήσει
το `sudo`. Έπειτα εγκαθιστά την εφαρμογή μόνο για τον δικό σας χρήστη.

Ανοίξτε το **Sound Tuner**, διαλέξτε τη συσκευή εξόδου και πατήστε
**Φόρτωση** στο πλαίσιο ειδοποίησης. Ο ήχος επανεκκινείται μία φορά για να
φορτωθεί το φίλτρο.

| Επιλογή | Τι κάνει |
|---|---|
| `--yes` | εγκαθιστά τις εξαρτήσεις χωρίς ερωτήσεις |
| `--no-deps` | παραλείπει τις εξαρτήσεις, εγκαθιστά μόνο την εφαρμογή |
| `--dry-run` | δείχνει τι θα εγκαθιστούσε, χωρίς να αλλάξει τίποτα |
| `--uninstall` | αφαιρεί την εφαρμογή και το φίλτρο PipeWire (κρατά τις προρρυθμίσεις σας) |

### Εξαρτήσεις

Εγκαθίστανται για εσάς από το `install.sh`:

- Εργαλεία PipeWire: `pw-cli`, `pw-dump`, `pw-record` και `pactl`
- Python 3 με GTK 4 και libadwaita 1.5+
- Ο περιοριστής ZaMaximX2 από το [zam-plugins](https://github.com/zamaudio/zam-plugins)
- Η υποστήριξη LV2 του PipeWire για το filter-chain

Χρειάζεστε ένα περιβάλλον εργασίας που ήδη τρέχει PipeWire με WirePlumber,
κάτι που είναι η προεπιλογή στα τρέχοντα Fedora, Ubuntu, Debian και Arch.
Τα ονόματα πακέτων του Fedora είναι δοκιμασμένα· σε άλλες διανομές, αν έχει
αλλάξει το όνομα κάποιου πακέτου, το σενάριο σάς λέει τι λείπει ώστε να το
εγκαταστήσετε μόνοι σας.

## Πώς λειτουργεί

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

Η δομή του γραφήματος εξαρτάται μόνο από τα κανάλια της συσκευής. Όλα τα
υπόλοιπα είναι παράμετροι, και η απενεργοποίηση μιας λειτουργίας απλώς τη
θέτει σε ουδέτερη τιμή, όπως 0 dB ή ένα φίλτρο μετακινημένο έξω από το
ακουστό φάσμα.

Το εφέ 3D είναι το RACE αναπτυγμένο σε δύο όρους:
`out = own − g·D(other) + g²·D₂(own)`, περιορισμένο στη ζώνη 250 Hz–5 kHz.
Τα γραφήματα φίλτρων του PipeWire δεν μπορούν να περιέχουν βρόχους
ανάδρασης, οπότε δεν είναι πλήρως αναδρομικό.

Το φάσμα διαβάζεται με το `pw-record` από τη συσκευή που ρυθμίζετε, και μόνο
όσο είναι ανοιχτό το παράθυρο.

## Συμβουλές

- **Laptop:** εφαρμόστε τη διάταξη *Μικρά ηχεία* (αποκοπή κάτω από 120 Hz) και
  προσθέστε 6–10 dB ενίσχυσης. Περίπου αυτό κάνουν οι βελτιώσεις ήχου των
  Windows, όπως το Dolby, στα περισσότερα laptop.
- **Subwoofer:** εφαρμόστε τη *Διαχείριση μπάσων (80 Hz)* και μετά ρυθμίστε
  με ακρίβεια τη στάθμη και την καθυστέρηση του subwoofer μέχρι τα μπάσα να
  ακούγονται ομοιόμορφα από τη θέση σας.
- **3D:** καθίστε στο κέντρο, ορίστε τον βαθμό 3D γύρω στο 70% και μετά
  αλλάξτε την καθυστέρηση 3D μέχρι ο ήχος να απλωθεί πέρα από τα ηχεία.
- Το **overdrive** στέλνει ψαλιδισμένο ήχο στα ηχεία σας. Χρησιμοποιήστε το
  με φειδώ σε μικρά μεγάφωνα.
