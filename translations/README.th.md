Sound Tuner คือ EQ, ครอสโอเวอร์ และตัวจูนลำโพงแบบทั้งระบบสำหรับเดสก์ท็อป Linux
ที่ใช้ PipeWire โดยจะเพิ่มเอาต์พุตเสมือนชื่อ **Sound Tuner** ไว้ด้านหน้าอุปกรณ์เสียงใดก็ได้
ตั้งแต่ลำโพงในตัวของโน้ตบุ๊ก ไปจนถึงลำโพงสเตอริโอคู่กับซับวูฟเฟอร์ หรือชุด 7.1 เต็มรูปแบบ
และทุกแอปจะเล่นเสียงผ่านมัน

## ฟีเจอร์

- **EQ ที่วาดได้:** ลากผ่านกราฟไปทางไหนก็ได้เพื่อวาดเส้นโค้ง หรือจะลากจุดทีละจุดก็ได้
  เส้นโค้งจะผ่านจุดที่คุณวางไว้พอดี (แอปคำนวณเกนของฟิลเตอร์ให้เอง) และคุณสามารถ
  เลื่อนเพื่อขยายหรือบีบแบนด์ หรือพิมพ์ค่าความถี่ เกน และความกว้างแบบตรงเป๊ะได้
  ด้านหลังเส้นโค้งจะแสดง**สเปกตรัมแบบสด**ของเสียงที่กำลังเล่นอยู่
- **การส่งสัญญาณและครอสโอเวอร์แยกตามช่องสัญญาณสำหรับทุกรูปแบบ** (2.0, 2.1, 4.0, 5.1,
  7.1, …) สำหรับลำโพงแต่ละช่อง คุณตั้งค่าได้ดังนี้:
  - แหล่งสัญญาณ: ช่องเดียวกัน, ซ้าย, ขวา, โมโน, ทุกช่องสัญญาณ (สำหรับซับ) หรือปิด
  - ฟิลเตอร์ครอสโอเวอร์ไฮพาสและโลว์พาส (Linkwitz-Riley, 24 dB/oct)
  - ระดับ, ดีเลย์ (สำหรับปรับเวลาให้ตรงกัน) และขั้ว
- **ตั้งค่าช่องสัญญาณได้ในคลิกเดียว:** ตัดต่ำสำหรับลำโพงขนาดเล็ก, แยกซ้ายเบส /
  ขวาเสียงแหลมสำหรับโน้ตบุ๊ก, สเตอริโอไปทุกลำโพง และการจัดการเบส 80 Hz
  สำหรับระบบที่มีซับวูฟเฟอร์
- **ความดัง:** บูสต์ได้สูงสุด +20 dB เข้าสู่ลิมิตเตอร์แบบมองล่วงหน้า (ZaMaximX2)
  พร้อม**โอเวอร์ไดรฟ์**เสริมสำหรับตอนที่อยากให้ดังกว่าที่เสียงสะอาดจะทำได้
  และสวิตช์ที่ให้ตัวเลื่อนระดับเสียงของ GNOME ไปได้เกิน 100%
- **3D:** ความกว้างสเตอริโอ และการตัดครอสทอล์กแบบ Ambiophonics/RACE
  ซึ่งกระจายเสียงให้กว้างกว่าลำโพงที่วางชิดกัน เช่น ลำโพงของโน้ตบุ๊ก
- **พรีเซ็ต:** รายการอยู่ด้านบนของหน้าต่าง คลิกเพื่อโหลด หรือบันทึกเสียงปัจจุบัน
  เป็นพรีเซ็ตใหม่ การเปลี่ยนแปลงจะถูกบันทึกลงในพรีเซ็ตที่ใช้งานอยู่ไปเรื่อยๆ

## เทียบกับ Easy Effects, JamesDSP และอื่นๆ

- **UI ทันสมัย ใช้ง่าย:** หน้าจอเดียวที่เรียบร้อย วาดเส้นโค้ง EQ ตั้งค่าความดังและ
  3D แล้วเลือกพรีเซ็ต โดยไม่ต้องขุดหาในแผงปลั๊กอิน แถมยังรองรับมือถือ
  ปรับตัวได้ตั้งแต่โทรศัพท์จนถึงจอเดสก์ท็อปกว้างๆ
- **ไม่ต้องเปิดค้างไว้:** การประมวลผลทำงานอยู่ภายใน PipeWire เอง ปิดแอปไปแล้ว
  เสียงก็ยังคงถูกจูนไว้ตั้งแต่ล็อกอินเป็นต้นไป
- **มัลติแชนเนลของจริง:** 5.1 ยังคงเป็น 5.1 พร้อมครอสโอเวอร์ ดีเลย์
  และการจัดการเบสแยกตามช่องสัญญาณ
- **เสียงไม่สะดุด:** การเปลี่ยนแปลงมีผลกับฟิลเตอร์ที่กำลังทำงานอยู่แบบสดๆ
- **เล็กจิ๋ว:** ไฟล์ Python ไฟล์เดียว กับคอนฟิก PipeWire ที่อ่านเข้าใจง่ายอีกไฟล์เดียว
- **คลิปยาก:** ท้ายสายการประมวลผลจะเป็นลิมิตเตอร์แบบมองล่วงหน้าเสมอ ดูรายละเอียดด้านล่าง

### ทำไมแอป EQ อื่นถึงอาจให้เสียงแตกพร่า

EQ และการบูสต์เบสอาจดันสัญญาณให้เกิน 0 dBFS ซึ่งเป็นระดับสูงสุดที่ชิปเสียงเล่นได้
และเสียงจะคลิปถ้าไม่มีลิมิตเตอร์คอยรับไว้ Sound Tuner จะปิดท้ายด้วยลิมิตเตอร์
แบบมองล่วงหน้าที่ตั้งไว้ต่ำกว่า 0 dBFS เสมอ การบูสต์จึงทำให้เสียงดังขึ้นแทนที่จะแตกซ่า
(โอเวอร์ไดรฟ์จงใจข้ามส่วนนี้) นอกจากนี้การประมวลผลยังทำงานภายใน PipeWire เอง
แทนที่จะเป็นโปรเซสของแอปแยกต่างหาก จึงมีโปรแกรมที่ต้องตามให้ทันแบบเรียลไทม์น้อยลงหนึ่งตัว

## การติดตั้ง

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

สคริปต์จะติดตั้ง dependency ที่ขาดไปด้วยตัวจัดการแพ็กเกจของคุณ (dnf,
apt หรือ pacman) โดยจะแสดงคำสั่งที่จะรันจริงและถามก่อนใช้ `sudo`
จากนั้นจึงติดตั้งแอปให้เฉพาะผู้ใช้ของคุณ

เปิด **Sound Tuner** เลือกอุปกรณ์เอาต์พุต แล้วคลิก **Load** ในแบนเนอร์
ระบบเสียงจะรีสตาร์ทหนึ่งครั้งเพื่อโหลดฟิลเตอร์

| ตัวเลือก | หน้าที่ |
|---|---|
| `--yes` | ติดตั้ง dependency โดยไม่ถาม |
| `--no-deps` | ข้าม dependency ติดตั้งเฉพาะแอป |
| `--dry-run` | แสดงสิ่งที่จะถูกติดตั้ง โดยไม่เปลี่ยนแปลงอะไร |
| `--uninstall` | ลบแอปและฟิลเตอร์ PipeWire (เก็บพรีเซ็ตของคุณไว้) |

### Dependency

`install.sh` ติดตั้งให้คุณ:

- เครื่องมือ PipeWire: `pw-cli`, `pw-dump`, `pw-record` และ `pactl`
- Python 3 พร้อม GTK 4 และ libadwaita 1.5+
- ลิมิตเตอร์ ZaMaximX2 จาก [zam-plugins](https://github.com/zamaudio/zam-plugins)
- การรองรับ LV2 ของ PipeWire สำหรับ filter-chain

คุณต้องมีเดสก์ท็อปที่รัน PipeWire กับ WirePlumber อยู่แล้ว ซึ่งเป็นค่าเริ่มต้น
ของ Fedora, Ubuntu, Debian และ Arch รุ่นปัจจุบัน ชื่อแพ็กเกจของ Fedora
ผ่านการทดสอบแล้ว ส่วนดิสโทรอื่น หากชื่อแพ็กเกจเปลี่ยนไป สคริปต์จะบอกว่าขาดอะไร
เพื่อให้คุณติดตั้งเองได้

## หลักการทำงาน

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

โครงสร้างของกราฟขึ้นอยู่กับช่องสัญญาณของอุปกรณ์เท่านั้น ส่วนอื่นทั้งหมดเป็นพารามิเตอร์
และการปิดฟีเจอร์ใดจะตั้งค่าให้เป็นค่ากลาง เช่น 0 dB หรือย้ายฟิลเตอร์ออกไปนอกช่วงที่หูได้ยิน

เอฟเฟกต์ 3D คือ RACE ที่กระจายออกมาสองพจน์:
`out = own − g·D(other) + g²·D₂(own)` โดยจำกัดแบนด์ไว้ที่ 250 Hz–5 kHz กราฟฟิลเตอร์
ของ PipeWire ไม่สามารถมีลูปป้อนกลับได้ จึงไม่ได้เป็นแบบเรียกซ้ำเต็มรูปแบบ

สเปกตรัมอ่านด้วย `pw-record` จากอุปกรณ์ที่คุณกำลังจูน และอ่านเฉพาะตอนที่
หน้าต่างเปิดอยู่เท่านั้น

## เคล็ดลับ

- **โน้ตบุ๊ก:** ใช้การตั้งค่า *Small speakers* (ตัดต่ำ 120 Hz) แล้วเพิ่ม
  บูสต์ 6–10 dB ซึ่งก็ใกล้เคียงกับที่ระบบปรับปรุงเสียงของ Windows อย่าง Dolby ทำ
  บนโน้ตบุ๊กส่วนใหญ่
- **ซับวูฟเฟอร์:** ใช้ *Bass management (80 Hz)* แล้วปรับระดับและดีเลย์ของ
  ซับวูฟเฟอร์จนเบสฟังสม่ำเสมอ ณ ตำแหน่งที่คุณนั่ง
- **3D:** นั่งตรงกลาง ตั้งระดับ 3D ไว้ราว 70% แล้วปรับดีเลย์ 3D จนเสียง
  กระจายกว้างกว่าลำโพง
- **โอเวอร์ไดรฟ์**จะส่งเสียงที่คลิปแล้วไปยังลำโพงของคุณ ใช้อย่างพอประมาณกับไดรเวอร์ขนาดเล็ก
