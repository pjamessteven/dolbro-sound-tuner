Sound Tuner হলো PipeWire চালিত Linux ডেস্কটপের জন্য একটি সিস্টেম-জুড়ে EQ, ক্রসওভার
ও স্পিকার টিউনার। এটি যেকোনো সাউন্ড ডিভাইসের সামনে **Sound Tuner** নামে একটি
ভার্চুয়াল আউটপুট যোগ করে, ল্যাপটপের বিল্ট-ইন স্পিকার থেকে শুরু করে সাবউফারসহ
স্টেরিও জোড়া বা পূর্ণ 7.1 সেটআপ পর্যন্ত, আর সব অ্যাপ এর মধ্য দিয়েই বাজে।

## বৈশিষ্ট্য

- **যে EQ আপনি আঁকতে পারেন:** কার্ভ আঁকতে গ্রাফের উপর যেকোনো দিকে টানুন,
  অথবা আলাদা আলাদা পয়েন্ট সরান। কার্ভটি আপনার পয়েন্টগুলোর মধ্য দিয়ে যায়
  (ফিল্টারের গেইন অ্যাপ নিজেই হিসাব করে নেয়), আর স্ক্রল করে কোনো ব্যান্ড
  চওড়া বা সরু করতে পারেন, কিংবা ফ্রিকোয়েন্সি, গেইন ও প্রস্থের নির্দিষ্ট মান টাইপ করতে পারেন।
  যা বাজছে তার একটি **লাইভ স্পেকট্রাম** কার্ভের পেছনে আঁকা হয়।
- **যেকোনো লেআউটের জন্য প্রতিটি চ্যানেলের রাউটিং ও ক্রসওভার** (2.0, 2.1, 4.0, 5.1,
  7.1, …)। প্রতিটি স্পিকার চ্যানেলের জন্য আপনি ঠিক করেন:
  - উৎস: একই চ্যানেল, বাম, ডান, মনো, সব চ্যানেল (সাবের জন্য) অথবা বন্ধ
  - হাই-পাস ও লো-পাস ক্রসওভার ফিল্টার (Linkwitz-Riley, 24 dB/oct)
  - লেভেল, ডিলে (টাইম অ্যালাইনমেন্টের জন্য) ও পোলারিটি
- **এক ক্লিকে চ্যানেল সেটআপ:** ছোট স্পিকারের জন্য লো কাট, ল্যাপটপের জন্য বামে বেস /
  ডানে ট্রেবল ভাগ, সব স্পিকারে স্টেরিও, আর সাবউফারওয়ালা সিস্টেমের জন্য
  80 Hz বেস ম্যানেজমেন্ট।
- **লাউডনেস:** +20 dB পর্যন্ত বুস্ট, যা একটি লুক-অ্যাহেড লিমিটারে (ZaMaximX2) যায়,
  সঙ্গে ঐচ্ছিক **ওভারড্রাইভ** যখন পরিষ্কার সাউন্ডের সীমার চেয়েও জোরে চান,
  আর একটি সুইচ যা GNOME-এর ভলিউম স্লাইডারকে 100% ছাড়িয়ে যেতে দেয়।
- **3D:** স্টেরিও প্রস্থের সঙ্গে Ambiophonics/RACE ধাঁচের ক্রসটক
  ক্যানসেলেশন, যা ল্যাপটপের মতো কাছাকাছি বসানো স্পিকারের চেয়েও
  শব্দকে বেশি চওড়া করে ছড়িয়ে দেয়।
- **প্রিসেট:** উইন্ডোর উপরে একটি তালিকা। কোনোটিতে ক্লিক করলে সেটি লোড হয়, অথবা
  বর্তমান সাউন্ড নতুন প্রিসেট হিসেবে সংরক্ষণ করুন। পরিবর্তনগুলো সঙ্গে সঙ্গে সক্রিয় প্রিসেটে সংরক্ষিত হয়।

## Easy Effects, JamesDSP ইত্যাদির সঙ্গে তুলনা

- **আধুনিক, সহজ UI:** একটি পরিচ্ছন্ন স্ক্রিন। EQ কার্ভ আঁকুন, লাউডনেস ও
  3D ঠিক করুন, আর একটি প্রিসেট বেছে নিন, প্লাগইন প্যানেল ঘাঁটাঘাঁটি ছাড়াই। এটি
  মোবাইল-বান্ধবও, ফোন থেকে চওড়া ডেস্কটপ স্ক্রিন পর্যন্ত মানিয়ে নেয়।
- **কিছুই চালু রেখে দিতে হয় না:** প্রসেসিং চলে PipeWire-এর ভেতরেই। অ্যাপ
  বন্ধ করে দিন, লগইনের পর থেকেই আপনার সাউন্ড টিউন করা থাকবে।
- **সত্যিকারের মাল্টিচ্যানেল:** 5.1 থাকে 5.1-ই, প্রতিটি চ্যানেলের ক্রসওভার, ডিলে
  ও বেস ম্যানেজমেন্টসহ।
- **কোনো ড্রপআউট নেই:** পরিবর্তনগুলো চলমান ফিল্টারে লাইভ প্রয়োগ হয়।
- **একদম ছোট:** একটি Python ফাইল আর একটি সহজপাঠ্য PipeWire কনফিগ।
- **ক্লিপ করা কঠিন:** চেইনটি সবসময় একটি লুক-অ্যাহেড লিমিটারে শেষ হয়। নিচে দেখুন।

### অন্য EQ অ্যাপের সাউন্ড কেন বিকৃত শোনাতে পারে

EQ ও বেস বুস্ট সিগন্যালকে 0 dBFS-এর উপরে ঠেলে দিতে পারে, যা সাউন্ড চিপের বাজানোর
সর্বোচ্চ সীমা, আর কোনো লিমিটার না ধরলে সেটি ক্লিপ করে। Sound Tuner সবসময়
0 dBFS-এর নিচে সেট করা একটি লুক-অ্যাহেড লিমিটারে শেষ হয়, তাই বুস্ট করলে
কড়কড় না করে শুধু জোরে হয়। (ওভারড্রাইভ ইচ্ছাকৃতভাবে এটি এড়িয়ে যায়।) এর প্রসেসিংও
আলাদা অ্যাপ প্রসেসে নয়, PipeWire-এর ভেতরেই চলে, ফলে রিয়েল টাইমে তাল রাখতে হয় এমন
প্রোগ্রাম একটি কম।

## ইনস্টল

```sh
git clone https://github.com/pjamessteven/dolbro-sound-tuner.git
cd dolbro-sound-tuner
./install.sh
```

স্ক্রিপ্টটি আপনার প্যাকেজ ম্যানেজার (dnf, apt বা pacman) দিয়ে অনুপস্থিত সব
ডিপেন্ডেন্সি ইনস্টল করে। এটি সঠিক কমান্ডটি দেখায় এবং `sudo` ব্যবহারের আগে জিজ্ঞেস করে। তারপর
এটি শুধু আপনার ব্যবহারকারীর জন্য অ্যাপটি ইনস্টল করে।

**Sound Tuner** খুলুন, আপনার আউটপুট ডিভাইস বেছে নিন, এবং ব্যানারে **লোড করুন**-এ
ক্লিক করুন। ফিল্টার লোড করতে অডিও একবার পুনরায় চালু হয়।

| অপশন | এটি কী করে |
|---|---|
| `--yes` | জিজ্ঞেস না করেই ডিপেন্ডেন্সি ইনস্টল করে |
| `--no-deps` | ডিপেন্ডেন্সি বাদ দেয়, শুধু অ্যাপ ইনস্টল করে |
| `--dry-run` | কী ইনস্টল হবে তা দেখায়, কিছুই বদলায় না |
| `--uninstall` | অ্যাপ ও PipeWire ফিল্টার সরিয়ে দেয় (আপনার প্রিসেট থেকে যায়) |

### ডিপেন্ডেন্সি

`install.sh` এগুলো আপনার জন্য ইনস্টল করে:

- PipeWire টুল: `pw-cli`, `pw-dump`, `pw-record` ও `pactl`
- GTK 4 ও libadwaita 1.5+ সহ Python 3
- [zam-plugins](https://github.com/zamaudio/zam-plugins) থেকে ZaMaximX2 লিমিটার
- filter-chain-এর জন্য PipeWire-এর LV2 সাপোর্ট

আপনার এমন একটি ডেস্কটপ লাগবে যেটিতে আগে থেকেই WirePlumber সহ PipeWire চলছে, যা
বর্তমান Fedora, Ubuntu, Debian ও Arch-এ ডিফল্ট। Fedora-র প্যাকেজ নামগুলো
পরীক্ষিত; অন্য ডিস্ট্রোতে কোনো প্যাকেজের নাম বদলে গেলে স্ক্রিপ্টটি জানিয়ে দেয়
কী অনুপস্থিত, যাতে আপনি নিজেই সেটি ইনস্টল করতে পারেন।

## এটি কীভাবে কাজ করে

```
per input channel:   width (FL/FR) → 10-band EQ → 3D crosstalk cancellation (FL/FR)
per output channel:  source mix → high-pass → low-pass → level/polarity → delay
                     → limiter → overdrive → device channel
```

গ্রাফের লেআউট শুধু ডিভাইসের চ্যানেলের উপর নির্ভর করে। বাকি সবকিছু
একটি প্যারামিটার, আর কোনো ফিচার বন্ধ করলে সেটি একটি নিরপেক্ষ মানে সেট হয়, যেমন
0 dB বা শ্রবণসীমার বাইরে সরিয়ে দেওয়া একটি ফিল্টার।

3D ইফেক্টটি হলো দুটি পদে খুলে লেখা RACE:
`out = own − g·D(other) + g²·D₂(own)`, যার ব্যান্ড 250 Hz–5 kHz-এ সীমিত। PipeWire-এর
ফিল্টার গ্রাফে ফিডব্যাক লুপ থাকতে পারে না, তাই এটি পুরোপুরি রিকার্সিভ নয়।

স্পেকট্রামটি `pw-record` দিয়ে সেই ডিভাইস থেকে পড়া হয় যেটি আপনি টিউন করছেন, এবং শুধু
উইন্ডো খোলা থাকা অবস্থায়।

## টিপস

- **ল্যাপটপ:** *ছোট স্পিকার* সেটআপ (120 Hz লো কাট) প্রয়োগ করুন এবং
  6–10 dB বুস্ট যোগ করুন। বেশিরভাগ ল্যাপটপে Dolby-র মতো Windows এনহ্যান্সমেন্ট
  মোটামুটি এটাই করে।
- **সাবউফার:** *বেস ম্যানেজমেন্ট (80 Hz)* প্রয়োগ করুন, তারপর সাবউফারের লেভেল ও ডিলে
  এমনভাবে সূক্ষ্মভাবে ঠিক করুন যাতে আপনার আসনে বেস সমান শোনায়।
- **3D:** মাঝখানে বসুন, 3D পরিমাণ প্রায় 70%-এ রাখুন, তারপর 3D ডিলে সরাতে থাকুন যতক্ষণ না
  শব্দ স্পিকারের চেয়ে বেশি চওড়া হয়ে ছড়িয়ে পড়ে।
- **ওভারড্রাইভ** আপনার স্পিকারে ক্লিপ হওয়া অডিও পাঠায়। ছোট ড্রাইভারে
  এটি পরিমিতভাবে ব্যবহার করুন।
